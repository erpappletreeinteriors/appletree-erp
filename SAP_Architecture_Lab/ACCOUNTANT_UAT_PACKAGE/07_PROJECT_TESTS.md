# PROJECT TESTS

1. **Open "Project 360" for a test project.** Can you tell, at a glance, how much revenue, how much cost, and how much profit this project has so far?
2. **Check "Committed" vs. "Actual"** — these must be shown as two DIFFERENT numbers, never combined into one. Committed is money tied up in approved orders not yet received. Actual is real cost that's actually happened.
3. **Add a real cost to the project** (e.g., issue material, or post a labour cost) and confirm the project's Actual Cost and Profit update correctly.
4. **Invoice the customer for the project and record a receipt.** Confirm Revenue updates correctly.
5. **Calculate the project's profit yourself, by hand**, using the numbers you can see (Revenue minus Material minus Labour minus other costs). Compare it to what the system shows in "Project P&L." They should match exactly. If they don't, that's a serious FAIL — write down every number you used.
6. **Reverse one of the cost transactions** you created and check the project's profit corrects itself by exactly that amount.
