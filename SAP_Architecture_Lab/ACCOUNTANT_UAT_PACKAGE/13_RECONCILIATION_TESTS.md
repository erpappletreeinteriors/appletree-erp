# RECONCILIATION TESTS

After you've done a good number of the other tests, check these — they should ALL match exactly, with zero unexplained difference:

1. **Customer balances** (the "AR subledger") = the total Accounts Receivable shown on the Trial Balance.
2. **Supplier balances** (the "AP subledger") = the total Accounts Payable shown on the Trial Balance.
3. **Stock value** shown in Inventory = the Inventory value shown in accounting.
4. **Each bank/cash account's balance** on its own screen = its balance on the Reconciliation screen.
5. **Fixed Asset register** total = the Fixed Asset accounting total.
6. **Total Debits = Total Credits**, everywhere, always.

If any of these don't match, STOP and write down exactly what you did leading up to it — this is the single most important thing to report.
