# SERVICE / AMC / WARRANTY TESTS

1. **Log a warranty service ticket** against a completed test project and check that any material/labour cost from fixing it is tracked against that project.
2. **Log a chargeable (paid) service visit**, invoice the customer for it, and record a receipt.
3. **Set up a test AMC (Annual Maintenance Contract)** with a customer, bill it, and check how much revenue is "recognized so far" vs. how much is still "deferred" (not yet earned).
4. **Try to cancel an AMC contract partway through.** The system should NOT automatically decide what to do with the money already billed but not yet earned — it should clearly tell you this is a decision someone needs to make, not silently pick an answer.
