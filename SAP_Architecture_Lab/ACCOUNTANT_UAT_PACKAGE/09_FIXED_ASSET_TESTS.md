# FIXED ASSET TESTS

1. **Register a new asset** (e.g., a test machine) with a cost.
2. **Capitalize it** — this is the step where it officially becomes a company asset on the books (you'll be asked for useful life, depreciation method, and residual value — these are real accounting policy questions, answer with reasonable test values).
3. **Post depreciation** for one period. Check the asset's book value goes down by that amount.
4. **Transfer the asset** to a different location/person and check nothing about its value changes (a transfer is not a financial transaction).
5. **Dispose of the asset** with a sale amount, and check whether the system correctly shows a Gain or Loss depending on whether the sale amount was more or less than the asset's remaining book value.
6. **Check the Fixed Asset Reconciliation report** — the asset register total and the accounting (GL) total should match exactly.
