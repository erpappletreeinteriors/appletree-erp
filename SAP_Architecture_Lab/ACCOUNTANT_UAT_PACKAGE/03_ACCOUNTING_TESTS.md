# ACCOUNTING TESTS (Journal / Ledger Basics)

1. **Create a manual journal entry.** Pick any two accounts, put an amount on one side (Debit) and the same amount on the other side (Credit). Try to save it with different amounts on each side — it should refuse to save.
2. **Find the journal behind a transaction.** Create a customer invoice, then find the actual accounting entry it created. Can you tell which account got debited and which got credited?
3. **Reverse a journal entry.** Pick one you just created, reverse it, and check that the original is still there (not deleted) and a new "reversal" entry now cancels it out.
4. **Try to post into a closed accounting period.** Ask your admin to close a period for you first. Then try to post a normal transaction dated inside that closed period as an ordinary user — it should be blocked. Then try again as an authorized manager with a stated reason — it should be allowed, and there should be a record of who did it and why.
5. **Try posting a transaction dated far in the future** (e.g., a date next year). See what happens — does it warn you, block you, or ask for special approval?
6. **Check the Trial Balance.** Total Debits should exactly equal Total Credits. If they don't, that's a FAIL, not a rounding note.
