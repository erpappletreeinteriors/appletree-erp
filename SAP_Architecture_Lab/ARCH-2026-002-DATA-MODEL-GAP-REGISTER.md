# ARCH-2026-002 — Data Model Gap Register

**Date:** 2026-09-22. Phase 0 deliverable, §24. Covers every domain classified PARTIAL or ABSENT in
`ARCH-2026-002-MODULE-MATRIX.md`, plus the one REQUIRES-CLARIFICATION domain. EXISTING domains have no
entry here — their data model is already adequate for their current scope. No structure below is
implemented; this is a register of what a future wave would need to design, extending
`ARCH-2026-001-IMPLEMENTATION-WAVE-PLAN.md`'s own per-domain collection proposals rather than
re-deriving them from scratch, and re-verified against this Phase 0's fresh code audit.

## Notes

- **Per this CR's §14 instruction**, this register does not add Warehouse, Cost Centre, Profit Centre,
  or Department dimensions during Phase 0 — the prior finding that these are not all supported by the
  current data model in the same way is preserved, not silently resolved.
- **Per this CR's §35 instruction**, Payroll's row above proposes configuration-driven structures only
  — no statutory rate, slab, or rule is proposed as a default value anywhere in this register.
- No row in this register proposes a second GL writer, a second inventory-movement writer, a second
  project-cost model, a second audit mechanism, or a second document-numbering engine — every proposed
  structure is additive to, and reads/writes through, the existing four central engines confirmed
  singular in `ARCH-2026-002-DEPENDENCY-MAP.md` §5.
