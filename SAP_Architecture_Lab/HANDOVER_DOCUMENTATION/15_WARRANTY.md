# 15 — Warranty

## Creating a warranty
Tied to a customer, project, and (optionally) a Handover record. Duration in months must be explicitly entered — the system never assumes a default warranty period (e.g., it will not silently assume "1 year"). If duration is missing, creation is rejected with a message asking for it.

## Warranty vs Chargeable
When a complaint comes in, it must be classified as covered by Warranty (no charge to the customer) or Chargeable (a real invoice will be raised). This classification drives everything downstream — material and labour used on a Warranty visit become a real cost to Appletree (visible on Project Financial 360 as "Warranty Cost"), never billed to the customer.

## Cost visibility
Every Warranty-covered Service Visit's material and labour cost rolls up to the originating Project's Financial 360 and Company-Wide Project Profitability report — so warranty cost is never invisible or "off the books."

## Voiding / cancelling a warranty
Requires a reason, fully audited. Does not delete the record — the warranty stays visible with its final status and reason.
