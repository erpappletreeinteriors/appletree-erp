# 1. Sales → Project Setup

## 1.1 Create a Lead
Go to **Leads**. Add a new lead for a made-up test customer. Write down the Lead ID it gives you.

## 1.2 Create an Estimation Request
Go to **Estimation & Costing**. Create an estimation request against the lead you just made.

## 1.3 Enter Costing and Create a Quotation
Enter a simple costing (one material line is fine) and create a Quotation from it. Check that the quotation shows the price you expect.

## 1.4 Submit and Approve the Quotation
Submit the quotation. If it asks for a discount approval, log in as a Finance Manager or CEO test user to approve it.

## 1.5 Record Customer Acceptance
Record that the "customer" accepted the quotation (this is a test record, not a real e-signature).

## 1.6 Mark the Quotation as Won
Mark it Won. Check that:
- A new **Project** was created automatically.
- A new **Customer** record was created automatically (if one didn't already exist).
- The Project shows the correct approved revenue.

## 1.7 Check Project 360
Open **Project 360**, select your new project. You should see revenue, cost, and commitment figures — all starting near zero since nothing has happened yet.
