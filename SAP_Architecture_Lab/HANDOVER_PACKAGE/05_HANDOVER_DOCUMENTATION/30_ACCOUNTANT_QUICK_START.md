# 30 — Accountant Quick Start

## Logging in
Open the system in your browser, enter your username and password. You'll land on your Dashboard.

## Finding a customer or supplier
Sales/Finance menu group → Customers or Suppliers. Search by name.

## Creating a Customer Invoice
Finance → Customer Invoice → pick the customer, project, amount, tax code → Save as Draft → go to Document Workflow → Submit → (someone else) Approve → (someone else) Post.

## Creating a Supplier Bill
Same shape, Finance → Supplier Bill.

## Receiving money from a customer / Clearing AR
Finance → Customer Receipt → pick the customer, the specific open invoice, and the amount received → this posts and clears immediately.

## Paying a supplier / Clearing AP
Finance → Supplier Payment — same shape.

## Creating a Journal Entry
Finance → New Journal Voucher → add as many Debit/Credit lines as you need (minimum 2, must balance) → Save as Draft → Document Workflow → Submit/Approve/Post.

## Reversing a mistake
Never edit or delete a posted entry. Go to Document Workflow (or the Document Viewer), find the posted document, click Reverse, give a real reason. Both the original and the reversal stay visible forever.

## Viewing a project's cost and profit
Projects → Project 360 for the full breakdown, or Projects → Project P&L for just the margin.

## Importing a bank statement
Finance → ICICI Bank Import → paste the statement → Import → work through Match/Allocate/Exclude for each line.

## Reconciling the bank
Same screen, "Load Reconciliation" — shows the exact difference, if any, and what's still outstanding.

## Working with Fixed Assets
Finance → Fixed Assets. Register the asset, then Capitalize it (you'll be asked for Useful Life, Depreciation Method, and Residual Value — have these ready). Post Depreciation each period.

## Closing/reopening a period
Finance → Financial Periods. Close needs a reason; if you need to reopen a closed period for a genuine correction, that also needs a reason and the right role.

## Running a report / exporting data
Reports menu group — Trial Balance, AR/AP Ageing, Company Profitability, and Exports (real CSV downloads).

## Checking the audit trail
Reports → Audit Log (if your role has access) shows exactly who did what and when.
