# 5. Project Tests (Sales / Project Manager)

## 5.1 Lead to Quotation
Create a test Lead, an Estimation Request, a Costing, and a Quotation from it. Confirm the quotation price matches what you costed.

## 5.2 Customer Approval
Record the customer's acceptance.

## 5.3 Won → Project
Mark it Won. Confirm a Project and a Customer are both created automatically, with the correct approved revenue.

## 5.4 Drawing / BOQ / BOM
This system does not auto-generate a Bill of Quantities from a drawing — that step is manual, exactly as your real process is today. Create the Bill of Materials by hand for your test project, based on what you'd normally read off a drawing.

## 5.5 Project 360
Open Project 360 for your project. Confirm you can see Revenue, Commitment, Actual Cost, and Margin — and that "Actual Cost" reads the same number everywhere it appears on the page.

## 5.6 Second Project — Isolation Check
Create a second test project. Post a large made-up cost to it. Go back to your first project and confirm that cost did NOT appear there.
